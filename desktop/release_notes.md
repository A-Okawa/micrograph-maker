SEM・TEM・EPMA の像と EDS・WDS マップを並べた論文用の図を作るアプリ Micrograph Maker の PC 版です。Python もターミナルも要りません。データはその PC の中だけで扱います。

| | ダウンロードするファイル |
|---|---|
| Mac（Apple シリコン：M1〜、macOS 12 以降） | `MicrographMaker-*-mac.dmg` |
| Windows 10・11（64 ビット） | `MicrographMaker-*-windows-setup.exe`（インストーラー） |
| Windows（インストールできない PC） | `MicrographMaker-*-windows.zip`（展開して `MicrographMaker` フォルダの `MicrographMaker.exe`） |

### Mac
1. dmg を開き、`Micrograph Maker` を「アプリケーション」へドラッグします。
2. アプリケーションの Micrograph Maker をダブルクリックします。「開いていません」「確認できません」と出たら「完了」を押します。
3. システム設定 →「プライバシーとセキュリティ」を開き、下のほうの「“Micrograph Maker”は Mac を保護するためにブロックされました」の「このまま開く」を押し、パスワード（Touch ID）を入れて、もう一度「このまま開く」を押します。
   （macOS 14 以前なら、Micrograph Maker を control キーを押しながらクリック →「開く」→「開く」）
4. 2 回目からは、ダブルクリックだけで開きます。

### Windows
1. `MicrographMaker-*-windows-setup.exe` をダブルクリックします。「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
2. 案内に沿って進めます（管理者の権限は要りません）。デスクトップの Micrograph Maker のアイコンで開きます。

最初の 1 回は、開くまでに 1 分ほどかかることがあります。窓を閉じるとアプリは終わります。
アプリに Apple や Microsoft の署名が無いので、最初だけ上の確認が出ます（Windows 11 の「スマート アプリ コントロール」がオンの PC では開けません）。
